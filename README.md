# Personal_Podcast
Scalable full-stack podcast platform with episode management, search functionality, JWT authentication, and Azure Kubernetes deployment

## Tech Stack
- Backend: .NET Web API
- Frontend: React
- Database: SQL Server
- Containerization: Docker & Docker Compose
- Cloud Storage: Cloudinary
- Authentication: JWT
